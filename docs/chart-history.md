Chart history calls Vietcap's gap-chart endpoint through curl_cffi with Chrome 124 TLS/HTTP2 settings, browser headers, two attempts and a two-second total libcurl timeout per attempt. Under gevent, libcurl runs through the native thread pool to avoid blocking other requests. Transient upstream read timeouts are retried on a new connection; libcurl handles gzip/brotli response decoding before JSON parsing. Successful adjusted candles are cached under data/cache/chart_history, shared by workers and retained across restarts. These files stay separate from the raw VCI SQLite database to avoid mixing split-adjusted and unadjusted historical prices.

After both attempts fail, foreground calls skip further attempts for 30 seconds and use saved adjusted history, or SQLite if no saved history exists. Fallback responses or series behind the latest possible weekday session trigger up to six background refreshes. Each worker allows at most four concurrent refresh jobs and deduplicates each symbol/range for 60 seconds. Weekday freshness is a retry hint, not a holiday calendar. A newer SQLite session takes precedence over older saved candles. This bounds the usual upstream timeout delay to approximately four seconds; libcurl bounds the total transfer duration per attempt. The last returned data date should be checked when diagnosing upstream outages.

The price-history cron runs daily at 11:30, 16:30 and 20:30 in the VPS timezone (UTC+7). Incremental updates also refresh the last stored candle because an intraday candle may still change. The IQ price-history endpoint can lag behind gap-chart; a completed updater run alone does not prove today's session is available. Check MAX(time) per symbol.

Chart history bypasses Next/CDN response caching, since Flask already caches adjusted series and transient SQLite fallback responses must not be retained. A visible stock page refreshes history every 30 seconds and on focus/visibility changes, with overlapping fetches suppressed.

Sparse/illiquid symbols can have no candle on the current date even when the request succeeds. In a direct VBC gap-chart response on 2026-10-06 the latest returned candle was 2026-09-28; do not manufacture a current-day bar from zero-volume DB rows or the current-price endpoint timestamp.
