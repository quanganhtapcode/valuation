# News publisher logos

Official artwork retrieved from publisher sites on 2026-10-16. The source strip
shows every distinct publisher cited in `news_sources`, rather than every
publisher in this catalog. Different names, `www` URLs and subdomains map to the
same publisher. Each logo links to its first cited article.

Artwork is stored in `frontend-next/public/news-logos` as WebP, resized without
cropping or changing the brand artwork. Intrinsic dimensions reserve the image
space. Local files avoid hotlink failures and external logo requests for all
14 publishers currently present in the news database. White publisher artwork
uses a contrasting background. A new, unknown publisher uses its own favicon;
if an image fails, its name remains visible instead of hiding the source.
